## 2026-09-11 - Progressive Streaming and Token Authentication in Edge Workers and Object Storage
- **Context**: Creating an object-storage-backed media delivery service (`[REDACTED_CLOUD_RESOURCE]`) based on edge worker supporting progressive streaming, hotlink prevention, and authorization.
- **Learning**: HTML `<audio>`, `<video>`, and `<img>` tags cannot pass custom HTTP request headers (e.g., `Authorization: Bearer`). Enforcing header-only authentication forces clients to fetch media into in-memory JavaScript `Blob`s, breaking progressive streaming, Range seeking, and exhausting device RAM. Employing HMAC-SHA256 URL signing (`?token=...&expires=...`) allows browsers and native players (`AVPlayer`, `ExoPlayer`) to stream progressively using native HTTP 206 Partial Content. Furthermore, Edge Worker Cache API (`caches.default`) rejects 206 Range responses, so Range requests must stream directly from object storage while full GET requests benefit from normalized cache keys. In TypeScript, `R2Range` is a union of `{ suffix: number }` and `{ offset?: number; length?: number }`, requiring narrowing before arithmetic.
- **Action**: When designing media delivery workers, use URL query token signing with Web Crypto HMAC for client playback and preserve Range headers for object storage. Keep header API tokens for server-to-server minting and administrative routes.

## 2026-09-18 - Universal Long-Press Component Interaction and Consolidated MediaPlayerUI Architecture
- **Context**: Debugging non-functional long-press option buttons across media players and consolidating long-press behavior.
- **Learning**: Implementing long-press with separate `mousedown` and `touchstart` listeners introduces major mobile regressions: touch releases emit synthetic `mousedown` and `mouseup` events 0-300ms later, immediately invoking short-press logic and undoing long-press operations. Furthermore, real touchscreen fingers produce micro-pixel jitter, prematurely killing timers if `touchmove` lacks a distance threshold (e.g., 10px). A robust long-press implementation must unify interactions under Pointer Events (`pointerdown`, `pointermove`, `pointerup`, `pointercancel`), suppress trailing synthetic `click` events upon successful long-press execution (`suppressClick` flag with `preventDefault()` and `stopImmediatePropagation()`), enforce `touch-action: manipulation`, and provide full WCAG 2.0 keyboard accessibility (supporting `Enter` and `Space` for both tap and hold gestures). Consolidating `setupLongPress` directly inside `MediaPlayerUI.js` eliminates unnecessary `CustomEvent` dispatching, avoids global document scans, prevents memory leaks from bubbling synthetic events, and minimizes bundle and runtime overhead.
- **Action**: When binding long-press actions in media player components, use `UI.setupLongPress(button, { onShortPress, onLongPress, delay, moveThreshold })`. Never bind raw `touchmove` cancellations without a jitter threshold.

## 2026-09-18 - High-Performance Dynamic Listener Lifecycle & Zero-Idle DOM Overhead
- **Context**: Refactoring media player variants (`media-player.html`, `media-player-inline.html`, `components.html`) with 127+ preset buttons to use unified long-press.
- **Learning**: Binding passive or active `pointermove`, `pointerup`, and `mouseleave` listeners statically on large element collections (like 127+ preset track cards) generates heavy overhead and layout churn during scrolling. By adopting a dynamic listener lifecycle—attaching `pointermove`, `pointerup`, and `pointercancel` strictly on `pointerdown` and detaching them immediately on gesture release or cancellation—idle overhead is reduced to zero. Leveraging `setPointerCapture` and `releasePointerCapture` guarantees uninterrupted gesture tracking even if the pointer drifts, avoiding document-level listener leaks.
- **Action**: For list and grid item long-press interactions, dynamically bind motion listeners on pointer activation rather than statically registering them on all elements. Validate string selectors safely with try/catch when accepting polymorphic targets.
